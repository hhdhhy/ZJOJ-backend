## 🎨 文档规范

### 文件命名

- 使用大写字母和连字符：`01-GETTING_STARTED.md`
- 模块文档使用小写：`06-MODULES/judge.md`
- 数字前缀保证排序

### 标题层级

```markdown
# 一级标题（文档标题）

## 二级标题（主要章节）

### 三级标题（子章节）

#### 四级标题（详细内容）
```

### 代码块

```python
# 指定语言
def example():
    pass
```

```bash
# Shell 命令
echo "Hello"
```

### 表格

| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 值1 | 值2 | 值3 |

### 提示框

```markdown
> 💡 **提示**: 这是提示信息

> ⚠️ **注意**: 这是注意事项

> ❗ **警告**: 这是警告信息
```
