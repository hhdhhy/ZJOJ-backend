在论文中引用代码时，建议遵循以下格式：

```python

    """编译代码并缓存编译后的文件"""
```

**注意事项**：
- 只展示关键代码片段（不超过半页）
- 添加详细注释说明逻辑
- 标注代码所在文件和行号
- 避免展示完整的实现细节

## 📝 写作建议

### 学术规范

1. **术语统一**：全文保持术语一致（如"在线评测系统"而非混用"OJ系统"）
2. **引用规范**：所有引用的文献、技术文档都要在参考文献中列出
3. **图表编号**：按章节编号（如图 2-1、表 3-2）
4. **公式编号**：重要公式需要编号并在文中引用

### 语言风格

1. **客观陈述**：避免主观评价，用数据说话
2. **逻辑清晰**：段落之间要有明确的逻辑关系
3. **简洁明了**：避免冗长句子，一个句子表达一个意思
4. **专业术语**：首次出现的术语要给出定义或解释

### 常见错误

❌ **避免**：
- "这个系统非常好用"（主观评价）
- "我们做了很多优化"（模糊表述）
- 大量复制粘贴代码（应提炼核心逻辑）
- 图表没有标题和编号

✅ **推荐**：
- "测试结果表明，系统平均响应时间为 1.8s"（数据支撑）
- "通过引入 Redis 缓存，查询性能提升了 40%"（量化成果）
- "核心算法如代码清单 5-1 所示"（规范引用）
- "图 2-1 展示了系统总体架构"（图表说明）
