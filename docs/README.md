## 📋 项目概述

**ZJOJ（铸剑）** 是一个基于 Django 的在线评测系统，提供：

- ✅ 用户认证和权限管理
- ✅ 题目管理和测试用例
- ✅ 代码自动评测（C/C++/Python/Java）
- ✅ AI 智能问答助手
- ✅ 实时排名和统计

**技术栈**: Django + MySQL + go-judge + ChromaDB + DeepSeek
